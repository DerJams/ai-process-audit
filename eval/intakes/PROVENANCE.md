# Where these intakes came from

The three intake files in this folder were **generated by Gemini 3.1 Pro**. The judge
that scores them runs on **Claude**. Intake authorship and scoring authorship are
therefore different model families.

JSON has no comment syntax and the intake schema does not allow extra fields, so this
note lives beside the files rather than inside them.

## Why that matters

The engine is measured by comparing its scores against hand written gold labels. If
the same model both invented the businesses and scored them, an agreement number
would be partly measuring a model agreeing with its own habits: the phrasing it
reaches for, the way it describes a painful process, the level of detail it gives when
data is messy. That is a real effect and it flatters the result.

Having a different family write the intakes does not remove the problem, but it does
mean the engine is reading prose it did not write, in someone else's voice, with
someone else's idea of what a small business sounds like.

## The limitation that remains

**These are still synthetic businesses.** No one visited them, because they do not
exist. Every figure in these files was invented to be plausible rather than observed,
and plausible is not the same as real. Synthetic intakes are systematically tidier
than real ones in ways that are hard to see from inside: a real owner contradicts
himself, forgets a process entirely, gives a number he has not checked in three years,
and describes the thing that annoys him rather than the thing that costs the most.

The gold set only becomes fully real once actual prospect intakes accumulate. Until
then, agreement measured here says the engine behaves consistently against a
labeller's judgement on invented cases. It does not say the engine picks good
automation candidates for real businesses. Those are different claims, and this
project should keep making only the first one until it has the evidence for the
second.

## Current state

See [KNOWN_ISSUES.md](KNOWN_ISSUES.md). The current set has content problems found
after generation, and a corrected set is expected from Gemini before gold labelling
begins. Nothing in these files has been edited by hand, and nothing should be, since
hand editing them in Claude would undo the reason a different model wrote them.
